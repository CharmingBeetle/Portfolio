# Nina Thomas - Portfolio

A personal portfolio website showcasing my projects, skills, and experience as a junior software developer.

## Hosted
[https://portfolio-dev-nina.netlify.app/](https://portfolio-dev-nina.netlify.app/)

## 🚀 Features

- **Responsive Design** - Works perfectly on all devices
- **Modern UI** - Clean, professional design with Bootstrap 5
- **Contact Form** - Integrated with Netlify Forms for seamless communication
- **Project Showcase** - Detailed display of my development projects
- **Professional CV** - Comprehensive resume and skills section

## 🛠️ Technologies Used

- **HTML5** 
- **CSS3** 
- **Bootstrap 5**  
- **Netlify**
